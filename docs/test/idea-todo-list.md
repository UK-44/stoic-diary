# Idea 画面 TDD TODO リスト

t-wada 流 TDD の TODO リスト。テストを 1 つずつ Red → Green → Refactor で消化する。
実装が先に存在する項目は、テスト追加後に実装を一時的に壊して「テストが失敗すること」を確認してから Green に戻す（テストのテスト）。

凡例: `[x]` 済 / `[ ]` 未着手 / `[-]` 見送り（理由を併記）
